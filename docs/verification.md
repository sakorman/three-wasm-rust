# 验证范围

## 本次本地验收（2026-10-10）

- 环境：macOS / Apple Silicon、Rust 1.99.0、Node.js 20.20.2、wasm-bindgen 0.2.129、Chromium 156。
- `cargo fmt --check`、原生与 wasm32 两个目标的 Clippy 检查通过，均使用 `-D warnings`。
- 7 项 Rust 单元测试、8 项真实 WASM 差分测试、5 项 Chromium 端到端测试全部通过。
- 性能导出与零尺寸恢复两个回归场景额外各重复 4 次，全部通过。
- Vite 生产构建通过；生产预览实际加载 WASM、切换三种模式，无浏览器错误。
- 已人工查看桌面、20,000 对象场景、性能结果和 390px 移动端截图。
- npm 官方审计返回 0 个已知漏洞（仅代表本次检查时的依赖审计结果）。

浏览器自动化覆盖 Chromium；Firefox 与 Safari 尚未实际验收。后续提交的结果以 GitHub Actions 和重新执行测试为准。

## 正确性

| 需求 / 行为 | 验证方式 |
| --- | --- |
| WASM 来自 Rust，且不是 JS 占位实现 | wasm-pack release 编译；Node 加载实际 `.wasm`；检查导出的 WebAssembly.Memory |
| TRS、矩阵乘法、点变换与 Three.js 一致 | Rust 单测；128 组包含旋转、负缩放与非均匀缩放的 Three.js 差分 |
| 多层级场景、无序父节点、改父节点 | Rust 单测及真实 WASM 差分 |
| 拒绝循环、非法四元数、非有限输入 | Rust 单测和 JS-facing 异常断言，确认失败后状态不变 |
| 深层级与空场景 | 20,000 层 Rust 测试；WASM 空对象反复构造/释放 |
| 动画在两种计算路径中一致 | 5,000 节点在 0 / 0.5 / 3.25 / 100 秒比较世界矩阵 |
| 内存增长后的视图有效性 | 主动增长实际 WASM memory；验证旧视图失效、新视图正确 |

## 计时限制

浏览器测试的性能报告只证明采样与导出功能有效，不用于发布速度提升承诺。Headless Chromium 可能使用软件渲染，与真实 GPU 和显示器刷新率不同。

本项目没有为尚未实现的材质、模型加载、视锥剔除、GPU 完成计时或 WebGPU 提供测试。
