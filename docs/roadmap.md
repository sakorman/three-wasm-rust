# 开发计划

## 已完成

- 三角形射线查询采用一致的共享边符号判定，覆盖 4,096 组精确边中点、循环绕序、轴置换、镜像及浏览器可见接缝拾取。
- 层级场景、脏矩阵更新和视锥剔除。
- 逐对象与实例化渲染，分别和 Three.js 配对测试。
- CPU、帧间隔和 GPU 计时，支持导出原始样本。
- WebGL 上下文恢复，失效跑分取消和 GPU 资源重建。
- 负缩放与父节点镜像，逐对象朝向切换及实例化朝向分组。
- 自定义局部包围球，非原点球心在父子变换及上下文恢复后保持正确。
- 微小剪切下的保守球半径，极端缩放与等价投影矩阵的剔除回归。
- 世界矩阵溢出检查、队列版本绑定及错误修复后的场景恢复。
- 去除平移的表面导数和缩放稳定的面法线，覆盖镜像、unlit 与旧实验页。
- GPU 样本完整性校验，缺失样本不再生成中位数；查询生命周期回归。
- 矩阵乘法使用 f64 中间值，保留大数抵消后的局部偏移，拒绝最终溢出的数学接口结果。
- 点变换在 f64 中完成齐次除法，支持等价矩阵缩放并拒绝零 w 与最终溢出。
- 已有材质的颜色与 unlit 原地更新，共享材质同步生效，上下文恢复保留最新参数。
- 固定拓扑的几何体顶点更新，自动同步所有引用组的保守包围球，并保留恢复所需数据。
- 几何体拓扑替换，保持资源 ID 和对象引用，分配失败保留原几何，上下文恢复使用最新索引。
- 构造与恢复时校验实例缓冲容量，旧渲染器全部缓冲分配失败时清理资源。
- 资源重建失败后可在后续上下文恢复时再次重建，保留场景与相机，恢复前禁止绘制和跑分。
- GPU 报告记录查询分配失败、队列上限、无效结果、未返回查询及扩展缺失/disjoint 轮数。
- GPU 计时核对活动查询归属，跳过被占用的帧并拒绝中途被结束/替换的区间；导出报告累计冲突数，清理不干扰外部查询。
- GPU 资源对象数与缓冲字节快照，支持拓扑更新、分配失败回滚、上下文丢失/恢复和释放后检查。
- 批量世界 AABB 查询，支持层级、镜像、剪切及退化盒，使用保守舍入并拒绝失效场景和溢出。
- 射线与世界 AABB 的批量候选查询，返回参数区间，覆盖平行轴、范围裁剪和极端量级。
- 四元数归一化接受全部有限非零 f32 输入，包含次正规数，保留无效批次的原子拒绝。
- 索引三角形的批量射线查询，返回参数与重心权重，支持双面/背面剔除和范围限制。
- 上下文恢复回调的重入防护，回调中 dispose 后保持终止状态，失败后可继续下一次恢复。
- TS 相机矩阵乘法在 Number 中累加后统一写入 f32，拒绝无效输入和最终溢出。
- 高斯屏幕支持范围按不透明度收紧，包含正定协方差校验、半像素边界保护和真实 WebGL 像素对照。
- 高斯不透明度稳定索引筛选，保留原始顺序与阈值相等项，供后续投影、排序或上传步骤使用。
- 高斯候选的完整 f32 稳定深度排序，支持正负深度、同深度与正负零，验证透明混合结果。
- 高斯屏幕范围 binary16 向外打包，保持零支持与保守边界，验证着色器解包后的像素覆盖。
- 三维高斯协方差按透视 Jacobian 投影到屏幕空间，保留中心、深度和二维协方差供后续范围/排序链路使用。
- 投影出口校验实际 f32 协方差的正定性，拒绝舍入退化的批次；保留可表达的次正规方差，并验证后续范围、排序和绘制。
- 近远中心深度候选筛选，保留原始索引、边界项和候选顺序，与不透明度筛选、投影和排序衔接。
- 三维高斯支持范围深度筛选，按协方差 z 边际与不透明度阈值保留跨近远平面的候选，并使用保守 f64 端点。
- 高斯屏幕范围与视口相交筛选，保留边缘范围和原始顺序，验证 f32/binary16 绘制与精确数值参考。
- 二维高斯屏幕低通滤波，以返回的 f32 协方差行列式补偿峰值不透明度，供范围、视口与光栅阶段重算。
- 高斯范围的行优先瓦片分箱，保守保留边界相交项与候选顺序，并限制瓦片和引用分配。
- 高斯瓦片内稳定深度排序，保留偏移表和同深度输入顺序，校验完整的瓦片引用格式。
- 高斯仿射半空间裁切系数，支持将近平面表达为 `[0, 0, -1], -near`，并以条件高斯 CDF 验证单高斯裁切方向。
- 高斯视图准备接口，将候选筛选、投影、滤波、范围、视口、排序、裁切系数和分箱组织为同一紧凑局部数据视图。
- 高斯上传数据打包，将紧凑视图转为包含范围、逆协方差、不透明度和裁切状态的固定交错 f32 记录，并保留局部瓦片引用。
- 高斯打包出口校验 f32 逆协方差正定性，提前拒绝舍入退化的批次；保留有效次正规逆矩阵和极端非均匀尺度输入。
- 高斯上传缓冲，复用交错记录容量、隔离调用方数组，并在 WebGL 上下文恢复后自动重建并重传数据。
- 高斯上传视图的主动卸载：释放 CPU 副本和 VBO，恢复后不重传旧数据，后续上传可复用同一资源对象。
- 高斯绘制器卸载及扩容失败时断开所属 VAO 的旧缓冲引用，恢复调用方绑定，并验证重复重载和上下文恢复后的像素一致性。
- 高斯上传资源快照：分别统计内部记录、原始 ID 和瓦片副本字节数，以及当前可用 VBO 容量；丢失、失败、卸载和释放时 GPU 容量归零。
- 引擎保留的 CPU TypedArray 快照：构造后不持有完整输入场景，准确统计恢复所需的顶点、索引、批次和动画数组，并在释放后清空。
- 独立高斯光栅 pass，读取上传缓冲执行 CDF 裁切和预乘 alpha 合成，恢复后重建 shader/VAO 并保持像素结果。
- 高斯程序创建失败时清理临时 shader/program；覆盖连续构造失败、恢复失败后拒绝绘制以及再次恢复后的像素一致性。
- 高斯全屏与瓦片绘制显式设置加法混合方程，正常返回和异常退出均恢复调用方独立 RGB/alpha 方程，避免前序减法或 MIN/MAX 混合改变结果。
- 高斯屏幕空间合成隔离深度测试、深度写入和面剔除，正常/异常返回恢复调用方状态；全屏与瓦片路径均验证目标深度不变。
- 高斯瓦片绘制路径，按内部行优先瓦片—局部 ID 顺序设置 scissor，验证与全屏紧凑绘制的像素等价及状态恢复。
- 高斯瓦片连续记录分批，保留局部 ID 与混合顺序；非连续记录维持独立提交，并验证像素与状态不变。
- 高斯打包与上传统一校验瓦片引用，拒绝同瓦片重复 ID；无效更新保留当前资源及恢复副本，合法跨瓦片复用和合成顺序保持。
- 高斯线性 RGB 属性，保持源 ID、紧凑视图、交错上传和预乘 alpha 合成的颜色对齐；缺省输入使用白色。
- 原始 3DGS 二进制 PLY 输入，解码中心、激活后协方差、不透明度和 0 阶 SH 颜色；拒绝不完整或不兼容的顶点记录。
- PLY 模型空间到正 z 相机空间的显式仿射变换，中心采用 `R × c + t`，协方差采用 `R × Σ × Rᵀ`，并拒绝透视或奇异矩阵。
- Three.js 模型与负 z 视图矩阵在单次 Rust/WASM 调用中组合为正 z 高斯相机矩阵，校验输入和结果的仿射可逆性，核心不依赖 Three.js。
- 原始训练 PLY 的完整 0–3 阶 SH 系数组，按模型坐标系相机位置在 Rust/WASM 中求非负线性 RGB；不完整的 `f_rest_*` 组保持兼容性忽略。
- 原始 PLY 高阶 SH 从颜色通道分块转换为逐系数 RGB，完整校验组大小，避免不完整高阶组被误读为低阶前缀；覆盖 1–3 阶映射与正反视角像素。
- 世界相机位置到 PLY 模型空间的逆仿射转换，供 SH 方向求值使用；Three.js 调用方只传矩阵和位置副本。
- 从训练 PLY 和 Three.js 复制状态直接生成紧凑光栅视图，统一模型空间 SH 求值、正 z 相机变换、筛选、投影、排序与分箱。

## 待办

1. **数值边界**：评估相机相对坐标或原点重定位，改善 GPU 顶点投影精度；补齐退化几何的可见性测试，评估因子化高斯二次型在片元阶段的稳定性。
2. **资源管理**：动态增删节点、卸载几何体与材质、WASM/浏览器堆统计，以及重复加载压力测试。
3. **空间查询**：场景级拾取的坐标转换与对象映射、近退化和近共面输入的误差界及求交稳定性、BVH 构建与更新，评估 AABB 剔除与现有包围球的取舍。
4. **性能测试**：增加场景输入和浏览器覆盖，检查采样分布及传输成本。
5. **3DGS 管线**：将训练 PLY 的紧凑视图接入主渲染路径并处理相机/模型变更，设计高斯与 Mesh 共用的深度映射及遮挡策略，为稀疏瓦片 ID 设计 GPU 级地址间接与批量提交；补充交叠高斯的逐像素/近似透明度策略，用同模型、同视角测量帧耗时与 PSNR/SSIM，再评估 LoD、压缩和去噪。参考资料见[高斯光栅化准备](gaussian-rendering.md)。
6. **资产与材质**：模型加载、纹理、灯光，再逐步接入 PBR 和阴影。

## 设计约定

- Rust/WASM 核心与 Three.js 解耦，前端使用 TypeScript strict。
- 对照使用相同输入和渲染策略，报告明确精度、工作量和计时范围。
- 页面保持一屏布局，详细说明放在文档中。
- 每项优化随代码更新 [CHANGELOG](../CHANGELOG.md)，记录日期、具体行为变化、验证结果和已知限制。

构建与测试命令见 [README](../README.md#类型与测试)，覆盖范围见 [测试说明](verification.md)。
