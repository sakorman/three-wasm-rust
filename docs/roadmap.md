# 开发计划

## 已完成

- 层级场景、脏矩阵更新和视锥剔除。
- 逐对象与实例化渲染，分别和 Three.js 配对测试。
- CPU、帧间隔和 GPU 计时，支持导出原始样本。
- WebGL 上下文恢复，失效跑分取消和 GPU 资源重建。
- 负缩放与父节点镜像，逐对象朝向切换及实例化朝向分组。
- 自定义局部包围球，非原点球心在父子变换及上下文恢复后保持正确。
- 微小剪切下的保守球半径，极端缩放与等价投影矩阵的剔除回归。

## 待办

1. **变换校验**：处理层级累乘产生的非有限世界矩阵，补齐大坐标抵消及退化变换边界，保证无效更新不会提交旧队列。
2. **资源管理**：动态增删节点、卸载几何体与材质、内存统计及重复加载压力测试。
3. **空间查询**：AABB、射线拾取、BVH 构建与更新。
4. **性能测试**：增加场景输入和浏览器覆盖，检查采样分布及传输成本。
5. **资产与材质**：模型加载、纹理、灯光，再逐步接入 PBR、阴影和 3DGS。

## 设计约定

- Rust/WASM 核心与 Three.js 解耦，前端使用 TypeScript strict。
- 对照使用相同输入和渲染策略，报告明确精度、工作量和计时范围。
- 页面保持一屏布局，详细说明放在文档中。

构建与测试命令见 [README](../README.md#类型与测试)，覆盖范围见 [测试说明](verification.md)。
