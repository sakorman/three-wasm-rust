# 开发计划

## 已完成

- 层级场景、脏矩阵更新和视锥剔除。
- 逐对象与实例化渲染，分别和 Three.js 配对测试。
- CPU、帧间隔和 GPU 计时，支持导出原始样本。
- WebGL 上下文恢复，失效跑分取消和 GPU 资源重建。
- 负缩放与父节点镜像，逐对象朝向切换及实例化朝向分组。
- 自定义局部包围球，非原点球心在父子变换及上下文恢复后保持正确。
- 微小剪切下的保守球半径，极端缩放与等价投影矩阵的剔除回归。
- 世界矩阵溢出检查、队列版本绑定及错误修复后的场景恢复。
- 去除平移的表面导数和缩放稳定的面法线，覆盖镜像、unlit 与旧实验页。
- GPU 样本完整性校验，缺失样本不再生成中位数；查询生命周期回归。
- 矩阵乘法使用 f64 中间值，保留大数抵消后的局部偏移，拒绝最终溢出的数学接口结果。
- 点变换在 f64 中完成齐次除法，支持等价矩阵缩放并拒绝零 w 与最终溢出。
- 已有材质的颜色与 unlit 原地更新，共享材质同步生效，上下文恢复保留最新参数。
- 固定拓扑的几何体顶点更新，自动同步所有引用组的保守包围球，并保留恢复所需数据。
- 几何体拓扑替换，保持资源 ID 和对象引用，分配失败保留原几何，上下文恢复使用最新索引。
- 构造与恢复时校验实例缓冲容量，旧渲染器全部缓冲分配失败时清理资源。
- 资源重建失败后可在后续上下文恢复时再次重建，保留场景与相机，恢复前禁止绘制和跑分。
- GPU 报告记录查询分配失败、队列上限、无效结果、未返回查询及扩展缺失/disjoint 轮数。
- GPU 资源对象数与缓冲字节快照，支持拓扑更新、分配失败回滚、上下文丢失/恢复和释放后检查。
- 批量世界 AABB 查询，支持层级、镜像、剪切及退化盒，使用保守舍入并拒绝失效场景和溢出。

## 待办

1. **数值边界**：评估相机相对坐标或原点重定位，改善 GPU 顶点投影精度；补齐退化几何的可见性测试。
2. **资源管理**：动态增删节点、卸载几何体与材质、CPU/WASM 内存统计，以及缓冲容量复用和重复加载压力测试。
3. **空间查询**：射线拾取、BVH 构建与更新，评估 AABB 剔除与现有包围球的取舍。
4. **性能测试**：增加场景输入和浏览器覆盖，检查采样分布及传输成本。
5. **资产与材质**：模型加载、纹理、灯光，再逐步接入 PBR、阴影和 3DGS。

## 设计约定

- Rust/WASM 核心与 Three.js 解耦，前端使用 TypeScript strict。
- 对照使用相同输入和渲染策略，报告明确精度、工作量和计时范围。
- 页面保持一屏布局，详细说明放在文档中。
- 每项优化随代码更新 [CHANGELOG](../CHANGELOG.md)，记录日期、具体行为变化、验证结果和已知限制。

构建与测试命令见 [README](../README.md#类型与测试)，覆盖范围见 [测试说明](verification.md)。
