# 界面设计记录

2026-10-12：按使用反馈移除测试口径、报告上下文与底部说明，释放高度给画布。保留简短采样、完成、取消和设置变化提示，详细说明放在 README。

目标是一个可操作的图形测试工作台：在当前 532 × 863 窗口，以及常见桌面尺寸内，同时看到设置、双画布、实时状态和完整结果。

## 设计方案

- 颜色：雾灰 `#edf1f5` 做外壳，白色 `#ffffff` 放操作和数据，墨蓝 `#203247` 放正文，钢灰 `#c8d2df` 分隔区域。Rust 用铜色 `#aa633b`，Three.js 用蓝色 `#366f9b`。画布保留引擎本身的深色背景。
- 字体：Avenir Next 处理拉丁字母，PingFang SC / Noto Sans CJK SC 处理中文。数字使用等宽数字特性，标签不使用等宽字体或额外大写装饰。
- 布局：顶部品牌与运行状态；紧凑参数条；双画布占用剩余高度；下方固定高度的测试区；底部两行口径和范围提示。文字左对齐，结果数字采用相同列宽。
- 窄窗口：双画布继续并排，结果转成两列对照块，所有指标都保留。操作按钮槽位和结果区高度固定，采样期间不会把画布挤小。

```text
品牌 / 引擎状态                         文档
对照方式    场景    对象数   暂停 / 重置
┌ Rust 画布           ┬ Three.js 画布   ┐
│                    │                │
└ CPU / Draw / 可见   ┴ CPU / Draw / 可见┘
性能对照                   采样长度 / 运行
Rust 数据                         Three.js 数据
测量口径 / 当前范围
```

## 取舍

原来的大标题、英文眉题和三张说明卡片占用了画布与结果所需的空间。这里改成以实时场景为主体的工具布局，而不是缩小整张宣传页。保留真实指标和必要说明，不新增装饰图表或预设性能结论。

重点检查 532 × 863、390 × 844、1024 × 640、1280 × 720、1440 × 900。正常窗口内不需要整页或表格横向滚动；极小高度和高倍缩放时允许自然滚动，优先保证可读和可操作。
