# 界面规范

## 布局

参数栏在顶部，双画布占据中间的剩余空间，结果区固定在下方。窄窗口中结果排为两列，保留全部指标。测试、取消和导出按钮使用固定槽位，避免采样期间改变画布尺寸。

页面只保留控件、数据和简短状态。测试口径、指标解释及功能范围放在 README。

## 颜色与字体

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#edf1f5` |
| 操作与数据区域 | `#ffffff` |
| 正文 | `#203247` |
| 分隔线 | `#c8d2df` |
| Rust 标记 | `#aa633b` |
| Three.js 标记 | `#366f9b` |

拉丁字母使用 Avenir Next，中文使用 PingFang SC / Noto Sans CJK SC。结果数字启用 tabular-nums，文字左对齐。

## 适配

检查尺寸：532×863、390×844、1024×640、1280×720、1440×900。常规尺寸内一屏展示，极小高度或高倍缩放时允许滚动。

控件保留键盘焦点提示。系统开启“减少动态效果”时，场景初始暂停。
